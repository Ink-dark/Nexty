/k2a — 作者表链接下划线

作者样式表 a{underline} 与 UA 表路径对照，两行都应带下划线。

/gbk — GBK 编码页（charset=gbk）

标题/正文/标点无乱码，不进错误页。字节由 gbk-page.src.html 经 iconv 生成。

/redir — 302 → /landing/dir/page.html

落点正确；相对图片按落点解析（/stats 有 /landing/dir/dot.png）；相对链接应按落点解析为 /landing/dir/sub.html（历史缺陷，见 README）。

/cached — HTTP 缓存页（max-age=120）

导航两次后 /stats 的 /cached 计数仍为 1（第二次命中缓存）。

/font — @font-face（Space Mono）

两行字形明显不同；再次导航不重复抓取字体（/stats 无新增字体请求）。

/font404 — @font-face 404（不同 family 名）

两行同字体（系统回退）；无豆腐块、不报错。刻意用不同 family 名，避免命中会话级注册表。

/links/link-test.html — 链接点击（段落内 / 图片后）

单次点击即导航；图片与链接同排。

/links/link-body.html — body 直接行内 img + a

/links/link-index.html — 索引片段（img 与 a 同排）
