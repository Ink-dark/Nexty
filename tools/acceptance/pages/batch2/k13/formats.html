K13 图片格式：png / jpeg / gif / webp 并排

四张 8×8 fixture（crates/nexty-paint/tests/data/gen_k13_fixtures.py 生成， 经 /k13/img/* 路由出图），以 width/height 属性放大到 64×64 绘制。 每张应为同一幅四象限色块：左上红、右上绿、左下蓝、右下白。

PNG（无损：四色应精确）
JPEG（有损：允许压缩噪点与边缘振铃，象限色仍应可辨）
GIF（调色板：应与 PNG 一致；动图取帧 1）
WebP（有损：允许噪点，象限色仍应可辨）

判据

1. 四张图全部出现（不进错误页、不缺图缺尺寸）；
2. 每张均为四象限色块：左上红 / 右上绿 / 左下蓝 / 右下白；
3. jpeg / webp 允许有损噪点，象限主色可辨即可；gif 与 png 应基本一致。

解码路径：字节 → nexty-paint decode（内容嗅探）→ RGBA8 → DrawImage 放大绘制。
